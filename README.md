# Приемане (Arsten / Multiplan) – Trimble Connect 3D-viewer extension

Acceptance of formwork and rebar by the structural designer. Requests come from site photos uploaded in Pour status
("За приемане – Кофраж / Армировка"); the designer sees the photos and the pours in the model and decides:
approved / approved with remarks / rejected. Only the Connect group "4.1-STRUCTURAL DESIGNER" can decide.

Manifest: https://arsten2026-cell.github.io/trimble-connect-acceptance/manifest.json
